# references/

Expert knowledge loaded **on demand**, not with the skill body. Put here anything that is:

- long (multi-page runbooks, full schema catalogs, provider comparison matrices);
- consulted occasionally rather than every time the skill fires;
- stable reference material rather than instruction.

Link to each file from `SKILL.md` with a relative path and one line saying when to open it, e.g.

```markdown
For the full CIS control-to-task mapping, see [references/cis-mapping.md](references/cis-mapping.md).
```

`scripts/compliance-check.py` verifies every such reference resolves.
